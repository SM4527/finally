# FinAlly Project - the Finance Ally

FinAlly is feature-complete: backend, frontend and the Playwright E2E suite are built and passing.
Work from here is maintenance, fixes and enhancements, not building from scratch.

- `planning/PLAN.md` (included below) is the spec and the contract between frontend and backend. Keep code and spec in agreement; if a change alters behaviour, update PLAN.md too.
- `planning/MARKET_DATA_SUMMARY.md` summarizes the market data component; the other `planning/MARKET_*` and `MASSIVE_API.md` docs hold its detail.
- `planning/TEAM.md` describes how the agent team built the platform.
- Run, dev and test commands are in `README.md`.
